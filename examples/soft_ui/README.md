# Soft UI

A tour of what an app can draw in Starlight's Soft UI style (SLUI 1.0.5):
soft surfaces, the skin's fonts, aligned labels, a ring, a graph, the
segmented control, the primary button, a desktop notification and a modal
dialog with its veil. The three cards sit in a row on a wide window and in
a column on a narrow one (resize the window to see it).

- Source: src/main.c
- Bundle: bundle/app.ini
